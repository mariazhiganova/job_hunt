# Проект "JOB HUNT"

## Описание

В проекте реализована программа для поиска необходимых вакансий на платформе hh.ru с возможностью записи их в файл.

### Описание модулей

В пакете **src** находятся модули с основным функциональным кодом:
- В файле **api_connection** описан абстрактный _BaseParser_ класс подключения к API, а также дочерний класс _HH_ для подключения к API hh.ru

- В файле **file_handler** описан абстрактный класс _BaseFileHandler_ для работы с файлами: чтение, запись и удаление данных. А также дочерний класс _JsonFileHandler_ для работы с файлами формата json.

- В файле **vacancies** находится класс _Vacancy_ для создания вакансий, имеющих название, ссылку, зп и требования. Класс имеет метод строкового отображения, методы сравнения, валидации по зп, а также метод формирования словаря из атрибутов экземпляра и метод создания списка экземпляров класса.

- В файле **utils** находится дополнительная функция _sort_vacancies_ для сортировки вакансий по зарплате по убыванию и вывода топ-n (n задается пользователем).

В файле **main** реализована функция для взаимодействия с пользователем, связывающая основную функциональность в одну программу.

В файле **settings** путь к файлу для сохранения вакансий, а также до базовой директории.

### Установка

1. Клонируйте репозиторий

```commandline
git clone https://github.com/mariazhiganova/job_hunt.git

```

2. Установите зависимости

```commandline
poetry install
```

### Тестирование

Проект покрыт юнит-тестами Pytest. Они располагаются в пакете **tests**

Чтобы запустить тесты с оценкой покрытия выполните команду:

```commandline
poetry run pytest --cov
```

Чтобы сгенерировать отчет о покрытии в HTML-формате, где src — пакет c модулями, которые тестируем.
Отчет будет сгенерирован в папке htmlcov и храниться в файле с названием index.html.

```commandline
pytest --cov=src --cov-report=html
```
